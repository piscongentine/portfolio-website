# Shwet Purwar's Portfolio Website 🚀

This is my personal portfolio website, showcasing my work as a Data Scientist and ML Practitioner.

This repository is actively managed with [Claude Code](https://claude.com/claude-code). Agent: piscongentine.

---

## ⚙️ Tech Stack

React • TypeScript • GSAP • Three.js • WebGL • Vite

---

## 🛠️ Notes

This project uses `gsap-trial` plugins (SplitText, ScrollSmoother) for a couple of the scroll animations. Trial plugins are meant for local/development use; for production use, see [GSAP's official installation docs](https://gsap.com/docs/v3/Installation/) for licensing bonus plugins properly.
